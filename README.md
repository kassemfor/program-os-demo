## How it works

Open `index.html` in any browser. All data saves to your browser's localStorage. No server, no login, no internet required after first load.

**The 8 modules:**

1. **Dashboard** — Live program health (RAG, open risks, days to SteerCo)
2. **Program Charter** — Single source of truth (decision, counterfactual, outcome, boundaries, kill criteria)
3. **Stakeholders** — Influence/interest map with sentiment tracker
4. **Vendors** — Every external dependency with exit clause status
5. **RAID Log** — Risks, Assumptions, Issues, Dependencies (filterable, exportable)
6. **Weekly Status** — Auto-pre-filled from charter + RAID, exports as Markdown
7. **Steering Committee Pack** — Auto-generated one-pager (print to PDF)
8. **Decision Log + Scorecard Tracker** — Decision accountability + quarterly readiness trend

**Key features:**
- One-click JSON export for backup
- CSV export of RAID for Excel/Sheets
- Print-ready SteerCo pack (CSS print stylesheet built in)
- Mobile-responsive (works on phone for ad-hoc status reads)

## Privacy note

The OS stores everything in browser localStorage. This means:
- ✅ No server to maintain
- ✅ No privacy concerns (data never leaves the user's machine)
- ⚠️ If the user clears browser data, the OS is empty
- ⚠️ The OS is tied to one browser on one device

The first thing the dashboard shows after a fresh setup is a reminder to "Export regularly." Exporting the JSON takes 5 seconds and protects against the "I cleared my cache and lost everything" failure mode.
